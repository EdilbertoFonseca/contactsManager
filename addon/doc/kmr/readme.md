## Pêşkêş

Bi xêr hatin bo **Rêveberê Têkiliyê ji bo NVDA**!

Ev pêvek ji bo alîkariya bikarhênerên kor an jî yên kêmendamên dîtinê hate pêşxistin da ku lîsteya têkiliyên xwe bi awayekî pratîkî, gihîştî û bibandor birêve bibin.

Bi vê amûrê, hûn dikarin:

* Add, edit, delete, and search for contacts;
* Import and export contact lists in CSV format;
* Apply custom phone number formatting;
* Choose a custom location to store your contact database;
* Navigate an intuitive and fully keyboard-accessible interface.

## Lêkirinî

1. Di NVDA de, menûya **Amûr** veke û biçe **Dikana Pêvekan**.
2. Di bin tabloya **Ad-onên Berdest** de, qada **Lêgerîn** bikar bînin û li `Contact Manager` bigerin.
3. Hilbijêre, **Enter** bikirtîne an jî **Bikaranîn** bikirtîne, û **Sazkirin** hilbijêre.
4. Ji bo temamkirina sazkirinê NVDA ji nû ve bidin destpêkirin.

Piştî sazkirinê, pêvek amade ye ku were bikar anîn.

Dema ku hûn di navnîşê de têkiliyek hilbijêrin, hûrguliyên wan dê di qutiyek nivîsê ya tenê-xwendinê de werin nîşandan. Hûn dikarin bi karanîna tîpa yekem a navê têkiliyê di navnîşê de bigerin.

## Mîhengkirin

Bigihîje panela mîhengan ji:
**Menûya NVDA > Tercîh > Mîheng > Rêveberê Têkiliyê ji bo NVDA**

Vebijarkên berdest:

1. **Maskkirina jimara telefonê**: Ji bo sepandina maskeke formatkirinê `#` bikar bînin (mînak, ji bo hejmarên Brezîlyayî).
2. **Destûrê bide paqijkirina hemû têkiliyan** (`Alt+T`): Bişkokekê çalak dike da ku hemû tomarên di navnîşa têkiliyan de jê bibe.
3. **Çalakkirina importkirina CSV** (`Alt+I`): Bişkokek nîşan dide ji bo importkirina têkiliyan ji pelên CSV.
4. **Çalakkirina hinardekirina CSV** (`Alt+X`): Bişkokek nîşan dide ji bo hinardekirina lîsteya têkiliyan bo pelê CSV.
5. **Pelrêça pelê têkiliyê**: Ji bo hilanîna pelê rojeva xwe rêyek xwerû destnîşan bike.

## Gihîştina pêvekê

Hûn dikarin Gerînendeyê Têkiliyê bi du awayan vekin:

1. Kurterêya klavyeyê: `Windows+Alt+L`
2. Menûya NVDA: `NVDA+N > Amûr > Rêveberê Têkiliyê`

Di pencereya sereke de, hûn dikarin: +

* Add, edit, and delete contacts;
* Search for specific contacts;
* Import and export CSV files;
* Delete all records in the contact list (if enabled).

## Têkiliyek Nû Zêde Bike

1. Gerînendeyê Têkiliyan (`Windows+Alt+L` an jî bi rêya menuyê) veke.
2. Ji bo zêdekirina têkiliyeke nû `Alt+N` bikirtînin.
3. Qadan tije bikin.
4. Ji bo tomarkirinê `Alt+O` an jî ji bo betalkirinê `Alt+C` bikirtînin.

> **Nîşe:** Ji bo gerandina di navbera qadan de **Enter** bikar bînin.
> Dibe ku bişkoka **Tab** ji ber pirsgirêkek naskirî bi awayekî nepêşbînîkirî tevbigere.

## Guherandina Têkiliyekê

1. Ji lîsteyê têkiliyek hilbijêre.
2. `Alt+E` an `F2` bikirtînin.
3. Guhertinên xwe bikin.
4. Ji bo tomarkirinê `Alt+O` an jî ji bo betalkirinê `Alt+C` bikirtînin.

## Lêgerîna Têkiliyan

1. Peyvek lêgerînê binivîse (nav, telefon, an jî e-name).
2. Ji bo fîltrekirina encaman `Alt+P` bikirtînin.
3. Ji bo nûkirina navnîşa tevahî `Alt+A` an `F5` bikirtînin.

> Heke hevberdanek neyê dîtin, peyamek dê we agahdar bike.

## Kurterêyên Klavyeyê

### Paceya Sereke

| Action                  | Shortcut            |
| ----------------------- | ------------------- |
| Add new contact         | `Alt+N`             |
| Edit selected contact   | `Alt+E` or `F2`     |
| Remove selected contact | `Alt+R` or `Delete` |
| Search                  | `Alt+P`             |
| Refresh contact list    | `Alt+A` or `F5`     |
| Import CSV file         | `Alt+I`             |
| Export to CSV           | `Alt+X`             |
| Delete all contacts     | `Alt+T`             |
| Exit                    | `Alt+S`             |

> Ji bo **sererastkirin** an **rakirina** têkiliyekê, pê ewle bin ku ew di navnîşê de hatiye hilbijartin.
> Heke tu têkiliyek neyê hilbijartin, peyamek hişyariyê dê were nîşandan.

### Paceya Têkiliyê Zêdekirin/Guherandin

| Action  | Shortcut |
| ------- | -------- |
| Confirm | `Alt+O`  |
| Cancel  | `Alt+C`  |

> Hûn dikarin hemû pencereyan bi `Esc` an `Alt+F4` bigirin.

## Translation

Translations for this add-on are managed through the [NVDA Add-ons Crowdin project](https://crowdin.com/project/nvdaaddons).

To contribute a translation, create a Crowdin account, join the appropriate language team if required, and translate the available interface and documentation strings directly in Crowdin.

You can also use Poedit to work with `.po` and `.xliff` files locally. Completed translations are synchronized to the add-on repository through the localization workflow.

For questions or assistance, please join the [NVDA Translations mailing list](https://groups.io/g/nvda-translations).
