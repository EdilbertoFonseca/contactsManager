## Введение

Добро пожаловать в **Диспетчер Контактов для NVDA**!

Это дополнение было разработано, чтобы помочь незрячим или слабовидящим пользователям управлять своим списком контактов практичным, доступным и эффективным способом.

С помощью этого инструмента вы сможете:

* Добавлять, редактировать, удалять и искать контакты;
* Импортировать и экспортировать списки контактов в формате CSV;
* Применять пользовательский формат телефонного номера;
* Выбирать удобное место для хранения базы данных контактов;
* Управлять интуитивно понятным интерфейсом, полностью доступным с помощью клавиатуры.

## Установка

1. В NVDA, откройте меню **инструментов** и перейдите в **магазин дополнений**.
2. На вкладке **доступных дополнений**, используйте  поле **поиска** и ищите `Contact Manager`.
3. Выберите его, нажмите **Enter** или щёлкните **Применить**, и выберите **Установить**.
4. Перезапустите NVDA для завершения установки.

После установки дополнение готово к использованию.

При выборе контакта в списке его данные отобразятся в текстовом поле только для чтения. Перемещаться по списку можно, используя первую букву имени контакта.

## Конфигурация

Доступ к панели настроек осуществляется по следующему пути:
**Меню NVDA > Параметры > Настройки > Диспетчер Контактов для NVDA**

Доступные варианты:

1. **Маска номера телефона**: Используйте `#` для применения маски форматирования (напр., для бразильских номеров).
2. **Разрешить очистку всех контактов** (`Alt+У`): Добавляет кнопку для удаления всех записей в списке контактов.
3. **Включить импорт CSV** (`Alt+И`): Отображает кнопку для импорта контактов из файлов CSV.
4. **Включить экспорт в CSV** (`Alt+К`): Отображает кнопку для экспорта списка контактов в файл CSV.
5. **Папка файлов контактов**: Укажите пользовательский путь для хранения файла с расписанием.

## Доступ к дополнению

Открыть Диспетчер контактов можно двумя способами:

1. Сочетанием клавиш: `Windows+Alt+L`
2. Из меню NVDA: `NVDA+N > Инструменты > Диспетчер Контактов`

В главном окне вы сможете:

* Добавлять, редактировать и удалять контакты;
* Искать конкретные контакты;
* Импортировать и экспортировать файлы CSV;
* Удалять все записи в списке контактов (если эта функция включена).

## Добавление Нового Контакта

1. Откройте Диспетчер Контактов  (`Windows+Alt+L` или через меню).
2. Нажмите `Alt+Н` для добавления нового контакта.
3. Заполните поля.
4. Нажмите `Alt+О` для сохранения или `Alt+Т` для отмены.

> **Примечание:** Используйте **Enter** для навигации между полями.
> Клавиша **Tab** Может вести себя непредсказуемо из-за известной проблемы.

## Редактирование контакта

1. Выберите контакт из списка.
2. Нажмите `Alt+Р` или `F2`.
3. Внесите свои изменения.
4. Нажмите `Alt+О` для сохранения или `Alt+Т` для отмены.

## Поиск контактов

1. Введите поисковый запрос (имя, телефон или адрес электронной почты).
2. Нажмите `Alt+P` для фильтрации результатов.
3. Нажмите `Alt+О` или `F5` для обновления всего списка.

> Если совпадение не найдено, вы получите соответствующее сообщение.

## Горячие Клавиши

### Главное Окно

| Действие                  | Горячая клавиша            |
| ----------------------- | ------------------- |
| Добавить новый контакт         | `Alt+Н`             |
| Редактировать выбранный контакт   | `Alt+Р` или `F2`     |
| Удалить выбранный контакт | `Alt+У` или `Delete` |
| Искать                  | `Alt+P`             |
| Обновить список контактов    | `Alt+О` или `F5`     |
| Импортировать файл CSV         | `Alt+И`             |
| Экспортировать в CSV           | `Alt+К`             |
| Удалить все контакты     | `Alt+В`             |
| Выход                    | `Alt+Ы`             |

> Для **редактирования** или **удаления** контакта, Убедитесь, что он выбран в списке.
> Если контакт не выбран, отобразится предупреждающее сообщение.

### Окно Добавления/Редактирования Контактов

| Действие  | Горячая клавиша |
| ------- | -------- |
| Подтвердить | `Alt+О`  |
| Отмена  | `Alt+Т`  |

> Вы можете закрывать все окна с помощью `Esc` или `Alt+F4`.
